# ТЗ по ролям

Общее ТЗ проекта — [../TZ.md](../TZ.md). Здесь оно разбито на две роли.

| Роль                                            | ТЗ                 |
| ----------------------------------------------- | ------------------ |
| R — в основном Rust: симулятор, klend, проверки | [rust.md](rust.md) |
| T — в основном TS: ядро, веб, Connect, Kamino   | [ts.md](ts.md)     |

## Граница между ролями

T собирает инструкции. R их симулирует и проверяет. Связь между ними — HTTP-контракт `POST /simulate` (описан в [crates/sim/README.md](../crates/sim/README.md)). Контракт фиксируем **29.10** и дальше меняем только по договорённости.

Изменения относительно [../TZ.md](../TZ.md):

- симулятор — Rust-сервис `crates/sim` вместо `packages/sim`;
- симулятор деплоится на VPS (Surfpool на Vercel не запустить), веб — куда угодно;
- `packages/core` пишет T, кроме `compat.ts` (проверки совместимости) — это R.

## Структура репо

```
packages/core/          T (compat.ts — R)
crates/sim/             R
recipes/kamino-rescue/  T пишет код, R даёт порядок аккаунтов и замеры CU
apps/web/               T
fixtures/               общие: JSON-примеры запросов и ответов /simulate
```
